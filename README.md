# 💍 벤치에서 우승 반지까지

실제 NBA 30개 구단 중 하나를 맡아 트레이드·선수 훈련·작전으로 한 경기씩 이겨 우승 반지를 노리는 비공식 농구 단장·감독 시뮬레이션. 선수 소속과 기록은 NBA.com 2026-27 시즌 개인 기록(2026-11-11 기준)이고 능력치는 그 기록으로 계산한 게임용 수치입니다. 공식 로고 대신 팀 컬러 배지를 쓰며 NBA·각 구단과 무관합니다.

- 게임: https://jg5549701-hash.github.io/-/basketball/
- **구단 선택**: 실제 30개 구단(NBA.com 기록 전체(447위까지)를 현재 소속팀에 배치(구단당 12~15명), 나머지 벤치·유망주는 가상) 중 하나를 맡아요. 약팀일수록 어렵고 구단주 기대 승수도 낮아요.
- **한 번에 한 경기**: 82경기 정규시즌, 상위 16팀 플레이오프(7전 4선승). 자동 진행은 한 경기씩 진행 화면으로 보여줍니다.
- **작전**: 밸런스·3점 폭격·골밑 공략·전면 압박·지역 방어·주전 휴식. 상대 성향(3점 위주·골밑 위주·수비형·빠른 템포)과 상성이 맞으면 보너스. 접전 막판엔 마지막 작전을 직접 선택.
- **훈련**: 팀 훈련 방향(슈팅·플레이메이킹·골밑·수비·리바운드·팀워크·회복)과 집중 육성 선수 2명. 체력·부상·케미스트리 관리.
- **트레이드**: 상대 구단과 선수를 주고받는 제안(가치·연봉·로스터 규정 판단), AI 구단의 트레이드 제안, 마감은 50번째 경기.
- **비시즌**: 드래프트 → 재계약 → FA 영입. 구단주 신뢰가 바닥나면 경질.
- 진행 상황은 브라우저에 자동 저장됩니다.
