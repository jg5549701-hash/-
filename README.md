# 🏀 벤치에서 MVP까지

2라운드 막차로 지명된 무명 신인이 벤치 끝자리에서 시작해 리그 MVP를 노리는 농구 커리어 시뮬레이션.

- 게임: https://jg5549701-hash.github.io/-/basketball/
- 매주 훈련(7개 능력치, 고강도 선택)·휴식·영상 분석·미디어 중 하나를 고르면 경기가 진행됩니다.
- 실력(OVR)과 감독 신뢰에 따라 벤치 → 로테이션 → 식스맨 → 주전 → 에이스로 출전 시간이 늘어납니다.
- 접전 상황의 마지막 공격(3점/점퍼/돌파/패스)을 직접 고르는 클러치 타임, 랜덤 이벤트, 올스타, 플레이오프, 시상식(MVP·신인왕·식스맨 등), FA·트레이드, 노쇠와 은퇴까지.
- 진행 상황은 브라우저에 자동 저장됩니다.

# 🏀 플레이메이커

드래그로 패스·슛하고 스크린·픽앤롤·랍 패스 같은 전술을 지시하는 농구 게임. (‘벤치에서 MVP까지’와는 별개의 게임)

- 게임: https://jg5549701-hash.github.io/-/playmaker/
- ‘나’를 기준으로 드래그해서 동료에게 놓으면 패스, 림에 놓으면 슛, 빈 곳에 놓으면 드리블. 드래그하는 동안은 슬로모션이고 예상 슛 성공률이 표시됩니다.
- 패스할 때 전술 선택: 📨 일반 / 🪂 랍(롤·컷하는 동료면 앨리웁) / ↩️ 기브앤고.
- 공을 쥐면 🧱 스크린 요청 · 🔁 픽앤롤 · 🎯 픽앤팝 · ✂️ 백도어 컷 · 🧹 아이솔, 동료가 공을 잡으면 🙋 패스 달라 · 🧱 스크린 걸기.
- 열면 바로 경기 시작. 쿼터마다 공격 3번 + 접전이면 마지막 공격, 끝나면 다시 하기.
