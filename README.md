# 💍 벤치에서 우승 반지까지

NBA 벤치 끝자리 신인에서 시작해 한 경기씩 쌓아 NBA 우승 반지를 노리는 농구 커리어 시뮬레이션. (구단 이름은 가상)

- 게임: https://jg5549701-hash.github.io/-/basketball/
- **입단 방식**: 로터리 픽 / 1라운드 후반(루키 계약) / 2라운드(2년 정규) / 미지명(Exhibit 10) 중 선택 → 트레이닝 캠프부터 시작.
- **한 번에 한 경기**: 82경기 정규시즌, 30팀 중 상위 16팀 플레이오프. 경기 전 준비(훈련·휴식·영상 분석·감독 면담 등)를 고르면 경기가 진행되고, 자동 진행은 한 경기씩 진행 화면으로 보여줍니다.
- **출전 시간**: 팀 뎁스 차트에서 같은 포지션 선수들과 경쟁.
- **계약**: 루키 스케일(팀 옵션), 정규, Exhibit 10, 해외(NBA 제안이 없을 때). 트레이드 요청, FA 시장의 여러 구단 제안·연봉 협상, 연장 계약.
- **경기**: 쿼터별 점수·주요 장면·감독 코멘트, 클러치 슛 선택, 경기 후 인터뷰.
- **시즌 사이**: 전환점 이벤트, 국가대표, 상점, 팬·기자 반응 피드.
- 진행 상황은 브라우저에 자동 저장됩니다.
