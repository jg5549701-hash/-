# 🏀 벤치에서 MVP까지

2라운드 막차로 지명된 무명 신인이 벤치 끝자리에서 시작해 리그 MVP를 노리는 농구 커리어 시뮬레이션.

- 게임: https://jg5549701-hash.github.io/-/basketball/
- 매주 훈련(7개 능력치, 고강도 선택)·휴식·영상 분석·미디어 중 하나를 고르면 경기가 진행됩니다.
- 실력(OVR)과 감독 신뢰에 따라 벤치 → 로테이션 → 식스맨 → 주전 → 에이스로 출전 시간이 늘어납니다.
- 접전 상황의 마지막 공격(3점/점퍼/돌파/패스)을 직접 고르는 클러치 타임, 랜덤 이벤트, 올스타, 플레이오프, 시상식(MVP·신인왕·식스맨 등), FA·트레이드, 노쇠와 은퇴까지.
- 진행 상황은 브라우저에 자동 저장됩니다.

# 🏀 코치의 작전판

선수는 그대로, 작전만 바꾸는 농구 전술 게임. 화이트보드 하프코트 위에 X·O로 작전이 그려지고 실행됩니다.

- 게임: https://jg5549701-hash.github.io/-/tactics/
- 공격 때는 상대 수비 대형(대인·스위치·드롭·블리츠·2-3 존·1-3-1 존)을 읽고 8가지 작전(픽앤롤, 픽앤팝, 포스트업, 하이-로우, 스태거, 백도어, 아이솔, 드라이브 앤 킥) 중 하나를 부릅니다.
- 수비 때는 상대 공격 세트를 보고 수비 전술을 고릅니다. 대인 계열 수비는 스크린이 걸리기 전엔 구분되지 않아, 관찰 기록과 작전 타임으로 추리해야 합니다.
- 작전 도중 수비 반응이 드러나는 순간 멈추고, 8초 안에 A·B·C 중 공을 보낼 곳을 고르는 '읽기' 단계가 있습니다. 상대 공격도 우리 수비를 읽고 전환합니다(강팀일수록 잘 읽음).
- 매 포세션의 판단을 기대 득점으로 평가하고, 경기 후 판단 등급(S~D)과 운(실제 − 기대 득점)을 보여줍니다.
- 같은 작전을 반복하면 상대가 읽고, 상대 AI는 자주 쓰는 작전에 맞춰 수비를 바꿉니다.
- 맞붙어 본 조합은 '작전 노트'(8×6 상성표)에 기록됩니다. 8강 → 4강 → 결승 토너먼트.
