# 🏀 벤치에서 MVP까지

2라운드 막차로 지명된 무명 신인이 벤치 끝자리에서 시작해 리그 MVP를 노리는 농구 커리어 시뮬레이션.

- 게임: https://jg5549701-hash.github.io/-/basketball/
- 매주 훈련(7개 능력치, 고강도 선택)·휴식·영상 분석·미디어 중 하나를 고르면 경기가 진행됩니다.
- 실력(OVR)과 감독 신뢰에 따라 벤치 → 로테이션 → 식스맨 → 주전 → 에이스로 출전 시간이 늘어납니다.
- 🎮 **직접 플레이**: 경기 중 하이라이트 공격(역할에 따라 1~3회)과 클러치 마지막 공격을 하프코트에서 드래그로 직접 플레이.
  - ‘나’를 기준으로 드래그해서 동료에게 놓으면 패스, 림에 놓으면 슛, 빈 곳에 놓으면 드리블/이동. 드래그하는 동안은 슬로모션이고 예상 슛 성공률이 표시됩니다.
  - 패스할 때 전술을 고릅니다: 📨 일반 패스(빠르지만 차단 위험) / 🪂 랍 패스(수비 머리 위, 롤·컷하는 동료면 앨리웁) / ↩️ 기브앤고(패스 후 컷 → 리턴 패스).
  - 공을 쥐고 있을 때 쓸 수 있는 지시: 🧱 스크린 요청 · 🔁 픽앤롤 · 🎯 픽앤팝 · ✂️ 백도어 컷 · 🧹 아이솔. 동료가 공을 잡았을 때는 🙋 패스 달라 · 🧱 스크린 걸기.
  - 홈 화면의 ‘🎮 직접 플레이’ 체크를 끄거나 ⏩ 자동 버튼을 누르면 예전처럼 자동으로 처리됩니다.
- 랜덤 이벤트, 랜덤 이벤트, 올스타, 플레이오프, 시상식(MVP·신인왕·식스맨 등), FA·트레이드, 노쇠와 은퇴까지.
- 진행 상황은 브라우저에 자동 저장됩니다.
