# 🏀 벤치에서 MVP까지

2라운드 막차로 지명된 무명 신인이 벤치 끝자리에서 시작해 리그 MVP를 노리는 농구 커리어 시뮬레이션.

- 게임: https://jg5549701-hash.github.io/-/basketball/
- 매주 훈련(7개 능력치, 고강도 선택)·휴식·영상 분석·미디어 중 하나를 고르면 경기가 진행됩니다.
- 실력(OVR)과 감독 신뢰에 따라 벤치 → 로테이션 → 식스맨 → 주전 → 에이스로 출전 시간이 늘어납니다.
- 접전 상황의 마지막 공격(3점/점퍼/돌파/패스)을 직접 고르는 클러치 타임, 랜덤 이벤트, 올스타, 플레이오프, 시상식(MVP·신인왕·식스맨 등), FA·트레이드, 노쇠와 은퇴까지.
- 진행 상황은 브라우저에 자동 저장됩니다.

# 🏀 플레이메이커

개인기보다 **작전으로 이기는** 3D 농구 게임. (‘벤치에서 MVP까지’와는 별개의 게임)

- 게임: https://jg5549701-hash.github.io/-/playmaker/
- 매 공격 시작 시 플레이북에서 작전 선택(픽앤롤·픽앤팝·호른스·스페인 픽앤롤·스태거·백도어·아이솔·프리) → 팀이 자동으로 실행하고, ①② 리드 표시가 초록이 되면 그 선수가 오픈.
- 상대마다 수비 성향(드롭·스위치·블리츠)이 달라 같은 작전도 결과가 다르다. 스카우팅 리포트와 ★추천 작전 참고.
- 공 가진 선수를 드래그해 패스(일반/랍/기브앤고)·슛·드리블, 동료를 탭하면 개별 지시. 우리 팀이 공을 잡으면 슬로모션.
- 8팀 시즌 일정, 작전 포인트로 플레이북 해금과 팀 훈련(슈팅·패스·스피드), 작전별 성공 기록. 진행은 자동 저장.
- 세로로 든 폰에서도 화면을 돌려 항상 가로로 플레이.
