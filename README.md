# 🏀 벤치에서 MVP까지

고교 1학년 벤치에서 시작해 대학·드래프트·G리그를 거쳐 리그 MVP를 노리는 농구 커리어 시뮬레이션.

- 게임: https://jg5549701-hash.github.io/-/basketball/
- **고교 3년**: 집중 육성 능력치를 정하고 시즌을 보내면 주말리그 전·후반기, 협회장배 전국대회, 왕중왕전 결과와 시즌 요약이 나옵니다.
- **시즌 사이**: 전환점 이벤트(두 갈래 선택), 국가대표 발탁(U18·U19, 아시아컵, 아시안게임, 월드컵, 올림픽), 시즌당 1개 구매 가능한 상점, 팬·기자 반응 피드.
- **진로 선택**: 고교 졸업 후 대학 진학(장학금 제안 비교) / 드래프트 직행 / G리그 직행.
- **대학**: 팀 스타일별 훈련 보너스, 학점 관리(낮으면 출전 정지), 전국 토너먼트, 매년 드래프트 참가·잔류 결정, 철회 마감일.
- **드래프트**: 에이전트 선임 → 컴바인(측정 결과) → 팀 워크아웃 → 2라운드 32픽 지명.
- **계약 종류**: 1라운드 루키 스케일(팀 옵션), 정규, 투웨이(1군 13경기·WBL 플레이오프 불가), Exhibit 10(트레이닝 캠프 결과로 전환/방출), G리그, 10일 계약 콜업, 해외(유럽) 계약.
- **이적**: FA 시장에서 여러 구단 제안 비교·연봉 협상·시장 관망, 트레이드 요청 시 여러 구단 중 선택, 연장 계약 제안.
- **경기**: 팀 뎁스 차트로 출전 시간 결정, 쿼터별 점수·주요 장면·감독 코멘트, 클러치 슛 선택, 경기 후 인터뷰, 랜덤 이벤트.
- 진행 상황은 브라우저에 자동 저장됩니다.
