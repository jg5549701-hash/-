# 휴식 통장

공부한 만큼 휴식이 쌓이는 타이머 (PWA).

- 앱: https://jg5549701-hash.github.io/-/
- 휴대폰에서 열고 **홈 화면에 추가**(iOS Safari: 공유 → 홈 화면에 추가 / Android Chrome: 메뉴 → 앱 설치)하면 앱처럼 실행되고 오프라인에서도 동작합니다.
- `index.html`을 수정하면 `sw.js`의 `VERSION`을 올려주세요.

## 단어 시험지

PDF 단어장을 올리면 영어 단어 시험을 만들어 주는 페이지.

- 앱: https://jg5549701-hash.github.io/-/word-quiz/
- `apple 사과`, `1 abandon v. 버리다` 처럼 영어와 뜻이 같이 있는 PDF는 뜻까지 자동으로 읽음 (영어만 있으면 단어만 뽑아서 암기 카드로)
- 문제 수 조절, 무작위 출제, 객관식 / 뜻 쓰기 / 영어 쓰기 / 섞어서 / 암기 카드
- 입력하자마자 바로 채점, 틀린 것만 다시 풀기, 종이 시험지(정답지 포함) 인쇄
- 스캔한 사진 PDF는 글자가 없어서 못 읽음 → 단어 목록에 직접 붙여넣기
