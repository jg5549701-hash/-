# 🏀 벤치에서 MVP까지

2라운드 막차로 지명된 무명 신인이 벤치 끝자리에서 시작해 리그 MVP를 노리는 농구 커리어 시뮬레이션.

- 게임: https://jg5549701-hash.github.io/-/basketball/
- 매주 훈련(7개 능력치, 고강도 선택)·휴식·영상 분석·미디어 중 하나를 고르면 경기가 진행됩니다.
- 실력(OVR)과 감독 신뢰에 따라 벤치 → 로테이션 → 식스맨 → 주전 → 에이스로 출전 시간이 늘어납니다.
- 접전 상황의 마지막 공격(3점/점퍼/돌파/패스)을 직접 고르는 클러치 타임, 랜덤 이벤트, 올스타, 플레이오프, 시상식(MVP·신인왕·식스맨 등), FA·트레이드, 노쇠와 은퇴까지.
- 진행 상황은 브라우저에 자동 저장됩니다.

# 🥐 새벽 4시 빵집

반죽하고, 굽고, 팔고, 덱을 키우는 골목 빵집 경영 덱빌딩 카드게임.

- 게임: https://jg5549701-hash.github.io/-/bakery/
- 매일 카드 5장을 뽑고 기력(⚡3)으로 재료·반죽·행동·시설 카드를 냅니다.
- 반죽 카드를 재료와 함께 오븐에 넣으면 며칠 뒤 빵이 진열대에 나오고, 영업 종료 때 손님이 사 갑니다. 안 팔린 빵은 다음 날 할인, 그다음 날 폐기.
- 상점에서 카드 구매·재료 구매·카드 폐기로 덱을 다듬고, 야근(⚡+2, 대신 피로 카드)과 예약 주문, 날씨·축제 같은 일일 이벤트를 활용하세요.
- 매주 월세를 내며 28일을 버티면 돈·평판·시설로 등급(S~D)을 매깁니다. 진행 상황은 브라우저에 자동 저장됩니다.

# 🔬 트랜지스터 팹

「새벽 4시 빵집」을 반도체 공장으로 바꾼 경영 덱빌딩 카드게임.

- 게임: https://jg5549701-hash.github.io/-/chipfab/
- 원자재(웨이퍼·도펀트·구리)를 모아 투입 카드로 클린룸 장비(최대 6칸)를 돌리면 다이오드·쌍극 트랜지스터·발광 다이오드·전력 트랜지스터·논리 회로·메모리·중앙처리장치가 출하 창고에 들어옵니다.
- 칩마다 산화·노광·식각·배선 공정 단계를 거치며, 공정 단계 카드로 그날 바로 다음 단계로 넘길 수 있습니다.
- 수요 예보에서 오늘·내일 바이어와 원하는 칩을 미리 보고 생산을 계획합니다.
- 칩마다 수율에 따라 불량이 나고, 안 팔린 칩은 구형 재고 → 단종 처리됩니다.
- 손패는 화면 아래 부채꼴로 펼쳐지고, 카드를 한 번 누르면 설명, 한 번 더 누르면 사용합니다.
- 매주 팹 운영비를 내며 28일을 버티면 등급(S~D)을 받습니다.
